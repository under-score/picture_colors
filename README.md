# picturecolors
list dominant picture colors

An image is made of dots of many colors. Finding which colors are most frequently used in an image, is relatively easy. It is a matter of building an histogram. However, if you want to find which are the dominant tones, that is much harder, as the most frequently used colors may not be exactly the dominant tones. It is even more harder to name all these colors - here is an attempt to build a German and an English vocabulary.
